# Football Manager 3.2 — Edição Premium

- Design renovado, responsivo para celular e computador.
- Mercado ampliado com dezenas de jogadores atuais e lendas históricas.
- Caça Rato continua como o jogador mais caro; Zé Rato permanece entre os especiais.
- Abra `index.html` ou publique os arquivos na raiz do GitHub Pages.

**Nota:** não é possível listar literalmente todos os jogadores que jogaram ou ainda jogam futebol: são muitos milhões e não existe uma base única completa. Esta versão amplia bastante o elenco com nomes conhecidos, mas não representa uma lista universal sem exceção.
